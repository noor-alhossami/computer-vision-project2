# computer-vision-project2
University computer-vision project using Python
This project uses ResNet18, a convolutional neural network (CNN), to analyze medical images and classify them as either cancerous or non-cancerous. The model is trained on custom medical datasets for accurate predictions. Users can input medical images, and the model will output a prediction along with a confidence score, assisting healthcare professionals in early cancer detection.

Features:


Classifies medical images into cancerous or non-cancerous using ResNet18.

Provides confidence scores for predictions.

Easy-to-use Python interface for image input.

Trained on custom datasets for improved accuracy.


Requirements:


Python 3.x

PyTorch

OpenCV (opencv-python) and NumPy (numpy)

Trained model weights (resnet18.pth)
